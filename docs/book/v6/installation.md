# Installation

`dot-annotated-services` requires PHP `8.3` or newer.

Install `dotkernel/dot-annotated-services` by executing the following Composer command:

```shell
composer require dotkernel/dot-annotated-services
```

To [cache the parsed annotations](cache.md), also install any PSR-6 cache implementation, for example:

```shell
composer require symfony/cache
```
